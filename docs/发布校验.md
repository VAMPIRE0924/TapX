# 发布资产校验

每个新的正式 Release 应至少包含：

- `tapx-linux-amd64.tar.gz`
- `tapx-linux-arm64.tar.gz`
- 至少一个 `tapx-openwrt-<platform>.tar.gz`
- `install.sh`
- `tapx-update-manifest.json`
- `SHA256SUMS`

## SHA-256

在下载目录执行：

```sh
sha256sum -c SHA256SUMS
```

macOS 可对单个资产执行：

```sh
shasum -a 256 tapx-linux-arm64.tar.gz
```

输出必须与 `SHA256SUMS` 中的值完全一致。

## Manifest

`tapx-update-manifest.json` 记录发布版本、内置 Xray 兼容版本、平台资产名和 SHA-256。安装前应同时确认：

- manifest 中的资产名在当前 Release 中存在。
- manifest 中的 SHA-256 与本地计算值一致。
- 目标平台和 CPU 架构正确。
- 归档中包含 `LICENSE`、`COPYRIGHT` 和第三方许可声明。

公开仓库的校验工作流会在 Release 发布时重新执行上述检查。
