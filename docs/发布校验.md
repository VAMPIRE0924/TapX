# 发布资产校验

正式 Release 应包含以下入口：

- `tapx-linux-amd64.tar.gz`
- `tapx-linux-arm64.tar.gz`
- `tapx-openwrt-x86-64.tar.gz`
- `install.sh`
- `tapx-update-manifest.json`
- `SHA256SUMS`

当前 OpenWrt x86-64 归档应同时包含一个 APK 和一个 IPK，以及 TapX 与第三方许可文件。Linux ARM64 归档不是 OpenWrt 安装包。

## 校验 SHA-256

下载目标资产和同一 Release 的 `SHA256SUMS`。只下载了一个资产时，应筛选对应条目进行校验，不需要为校验而下载所有平台资产。

Linux：

```sh
asset='tapx-linux-amd64.tar.gz'
checksum="$(awk -v name="$asset" '$2 == name {print $1}' SHA256SUMS)"
test -n "$checksum" && printf '%s  %s\n' "$checksum" "$asset" | sha256sum -c -
```

macOS：

```sh
asset='tapx-linux-arm64.tar.gz'
checksum="$(awk -v name="$asset" '$2 == name {print $1}' SHA256SUMS)"
test -n "$checksum" && printf '%s  %s\n' "$checksum" "$asset" | shasum -a 256 -c -
```

将 `asset` 改为实际下载的完整文件名。命令必须输出 `OK`；若未找到条目、文件名不匹配或摘要不一致，都应停止安装。不要从其他版本复制 `SHA256SUMS`。

## 检查 manifest

`tapx-update-manifest.json` 记录版本、内置 Xray 兼容版本、平台资产名、包格式和 SHA-256。安装前确认：

- `releaseVersion` 与 Release 标签一致。
- 目标资产名真实存在于同一 Release。
- manifest 与 `SHA256SUMS` 中的摘要均等于本地计算值。
- 平台、CPU 架构和 OpenWrt 包格式符合目标设备。

## 检查归档内容

```sh
tar -tzf tapx-linux-amd64.tar.gz
tar -tzf tapx-openwrt-x86-64.tar.gz
```

Linux 归档应包含 `tapx-core`、`tapx-panel`、管理命令、安装器和许可文件。OpenWrt 归档应包含 `.apk`、`.ipk`、`LICENSE`、`COPYRIGHT`、`THIRD_PARTY_NOTICES.md`、`GO_THIRD_PARTY_LICENSES.txt` 和 `WEB_THIRD_PARTY_LICENSES.txt`。

公开仓库会在正式 Release 发布后自动复验资产存在性、SHA-256、manifest 和归档路径安全。工作流成功不替代目标设备的架构、固件和内核 ABI 检查。
