# 发布资产校验

正式 Release 应包含以下入口：

- `tapx-linux-amd64.tar.gz`
- `tapx-linux-arm64.tar.gz`
- 一个或多个 `tapx-openwrt-<platform>.tar.gz`
- `install.sh`
- `tapx-update-manifest.json`
- `SHA256SUMS`

OpenWrt 归档应同时包含一个 APK 和一个 IPK，以及 TapX 与第三方许可文件。

## 校验 SHA-256

在下载目录执行：

```sh
sha256sum -c SHA256SUMS
```

macOS 可单独校验某个文件：

```sh
shasum -a 256 tapx-linux-arm64.tar.gz
```

摘要不一致时不要安装，也不要从其他版本复制 `SHA256SUMS`。

## 检查 manifest

`tapx-update-manifest.json` 记录版本、内置 Xray 兼容版本、平台资产名、包格式和 SHA-256。安装前确认：

- `releaseVersion` 与 Release 标签一致。
- 目标资产名真实存在于同一 Release。
- manifest 与 `SHA256SUMS` 中的摘要均等于本地计算值。
- 平台、CPU 架构和 OpenWrt 包格式符合目标设备。

## 检查归档内容

```sh
tar -tzf tapx-linux-amd64.tar.gz
tar -tzf tapx-openwrt-<platform>.tar.gz
```

Linux 归档应包含 `tapx-core`、`tapx-panel`、管理命令、安装器和许可文件。OpenWrt 归档应包含 `.apk`、`.ipk`、`LICENSE`、`COPYRIGHT`、`THIRD_PARTY_NOTICES.md`、`GO_THIRD_PARTY_LICENSES.txt` 和 `WEB_THIRD_PARTY_LICENSES.txt`。

公开仓库会在正式 Release 发布后自动复验资产存在性、SHA-256、manifest 和归档路径安全。工作流成功不替代目标设备的架构、固件和内核 ABI 检查。
