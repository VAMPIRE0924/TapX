# TapX v0.2.40-r2

## 更新内容

- 修复部分 NetworkManager 环境中 TAP/TUN 网卡应用失败的问题，兼容新旧设备管理接口。
- 补齐 RHEL 系 Linux 的流量控制命令依赖。
- 区分配置保存失败、应用失败、已回滚和回滚未完成，显示本机及远程节点的具体失败原因。
- 改进监听端与连接端的 XHTTP、XDRIVE、gRPC、Sockopt、TLS、QUIC 和 TUN 参数表单及显隐条件。
- 修复面板域名含连续点等无效输入仍能保存的问题。

## 下载与安装

提供 Linux x86-64、Linux ARM64、OpenWrt x86-64 和 OpenWrt ARM64 四个平台的安装包。
两个 OpenWrt 归档均包含 APK 和 IPK，请按设备实际包管理器选择；APK 文件名为 `tapx-0.2.40-r2.apk`。

- [Linux 安装与升级](https://github.com/VAMPIRE0924/TapX/blob/main/docs/安装与升级.md)
- [OpenWrt 安装与升级](https://github.com/VAMPIRE0924/TapX/blob/main/docs/OpenWrt.md)
- [下载文件校验](https://github.com/VAMPIRE0924/TapX/blob/main/docs/发布校验.md)

升级前请备份现有配置，下载后核对本版本的 `SHA256SUMS`。
