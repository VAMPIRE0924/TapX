# v0.2.40-r6

## 更新内容

- 修复部分单 IP 复用客户端在连接恢复后无法重新取得地址的问题。
- 修复内置 Xray 帧连接退出不完整、心跳超时检测被阻塞的问题。
- 修复转发队列短暂拥塞导致整条连接中断的问题。
- 修复监听端恢复后仍显示旧异常，以及失败探针影响正常连接状态的问题。
- 调整设备通道测速仪表：自动刻度保持稳定，指针采用最近 1 秒显示窗口；原始样本和最终测速统计保持不变。

## r6 修订更新

- 修复测速采样受事件发送阻塞影响而出现瞬时虚高速率的问题。读字节计数时使用实际采样时间。
- 开始测速时先收集完整的 1 秒显示窗口；连接、预热和收尾阶段显示未测量状态，避免指针假归零。真实零速样本与最终统计保留。
- 节点列表中的 TapX-UI、TapX、内置 Xray 版本支持点击，选择版本后更新对应远程节点。TapX-UI、TapX 与内置 Xray 按兼容整包安装。
- 更新版本列表增加 `dev`，同时显示实际开发构建版本。开发发行不替代默认稳定版。
- 支持主动重新安装同一正式修订，远程更新使用独立等待时间，并在重启后刷新节点状态。
- 修复前端开发与测试工具的已知安全问题。

## 升级说明

可在新版面板检查更新并选择 `v0.2.40-r6`。旧面板如因同版本限制无法更新，Linux 可使用安装脚本重新安装指定版本；OpenWrt 按平台文档使用包管理器 `--force-reinstall` 重新安装本次 r6 包。主管理面板更新后，即可点击节点版本号更新远端。升级会重新加载 TapX，活动连接可能短暂重连。升级前请备份配置。

本次修复不需要更改 OpenWrt 网络配置，也不需要调整 XHTTP 上传大小、发送间隔或传输模式。

## 下载与安装

提供 Linux x86-64、Linux ARM64、OpenWrt x86-64 和 OpenWrt ARM64 四个平台的安装包。两个 OpenWrt 归档均包含 APK 与 IPK，请按设备实际包管理器选择。

下载后核对同一版本的 `SHA256SUMS`。
