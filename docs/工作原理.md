# 工作原理

TapX 将管理面与数据面分离：面板负责对象配置、校验、生命周期和状态汇总；数据面负责真实的包转发、隧道传输和路由执行。

## 处理链路

1. 流量从系统网卡、TUN/TAP 设备或监听端进入。
2. 接入约束校验用户、vKey、地址范围和设备边界。
3. 分流规则根据源终端、目标地址、域名、GeoData 和规则集选择处理方式。
4. 路由和负载均衡选择具体连接端或本机出口。
5. 运行内核执行 Raw UDP、Raw TCP、内置 Xray 或外置 Xray 传输。
6. 面板汇总连接状态、流量、速度、延迟和诊断结果。

## 对象组合

TapX 不把复杂网络简化为固定套餐。监听端、连接端、用户、路由、vKey、设备和地址限制可独立建模，再按需组合。未配置的能力不应增加数据面的额外开销。

## 诊断

代理出站诊断以该连接端的真实代理链路为测试对象，包括 TCP/HTTP 连接、协议支持时的 UDP 请求延迟、出口信息和 Speedtest。诊断结果与运行状态、错误原因和实际传输应保持一致。
