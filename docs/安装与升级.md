# Linux 安装与升级

TapX 支持 Linux `amd64` 与 `arm64`。公开入口脚本会读取正式 Release 元数据、校验该 Release 中安装器的 GitHub SHA-256 摘要，再由安装器选择对应架构资产并核对 `SHA256SUMS`，最后启动交互式安装或维护向导。

## 安装前检查

- 使用具备 `systemd` 的 Linux `amd64` 或 `arm64` 系统。
- 准备 root 权限、`curl` 或 `wget`、`python3`、`tar` 和 `sha256sum`。
- 确认面板监听端口、登录入口和现有反向代理不会冲突。
- 已有安装升级前，备份数据库、配置、证书和外置 Xray 文件。

## 一键安装

```bash
curl -fsSL https://raw.githubusercontent.com/VAMPIRE0924/TapX/main/install.sh | sudo bash
```

安装过程中可选择语言、数据库类型、面板监听地址、端口、登录入口和管理员凭据。管理员凭据与 SSH 账号彼此独立，首次生成后应立即安全保存。

## 下载后执行

希望先检查脚本内容时：

```bash
curl -fLO https://raw.githubusercontent.com/VAMPIRE0924/TapX/main/install.sh
less install.sh
sudo bash install.sh
```

## 安装指定版本

```bash
curl -fsSL https://raw.githubusercontent.com/VAMPIRE0924/TapX/main/install.sh \
  | sudo TAPX_VERSION=0.2.2 bash
```

版本必须对应公开仓库中已发布的正式 Release。安装器不会安装草稿版本。

## 常用管理命令

```bash
sudo tapx status
sudo tapx restart
sudo tapx settings
sudo tapx logs
sudo tapx update
```

若系统尚未安装 `tapx` 管理命令，也可检查：

```bash
systemctl status tapx-panel tapx-core
journalctl -u tapx-panel -u tapx-core --since today
```

## 升级

1. 备份数据库、配置、证书和外置 Xray。
2. 记录当前面板地址、默认路由和管理链路。
3. 运行 `sudo tapx update`，或重新执行一键安装脚本。
4. 确认面板与核心版本、服务状态和 manifest 一致。
5. 使用连接端诊断验证代表性出口，再检查终端、接入和 DNS 分流。

升级失败时不要删除数据库或证书。先收集服务日志、安装器输出和当前版本，再按 [故障排查](故障排查.md) 处理。

## 卸载与数据

卸载程序和删除数据是不同操作。执行前确认是否需要保留数据库、备份、证书和 GeoData；不要通过手工删除服务文件代替正式维护命令。
