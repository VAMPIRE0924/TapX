# Linux 安装与升级

## 支持的资产

- `tapx-linux-amd64.tar.gz`
- `tapx-linux-arm64.tar.gz`

## 安装前

1. 核对主机架构与下载资产。
2. 下载同一 Release 的 `SHA256SUMS` 并校验。
3. 备份现有配置、数据库、证书和外置 Xray 文件。
4. 确保管理端口与现有服务不冲突。

## 安装

解压后运行包内的 `install.sh` 或 `tapx`。安装器负责安装 `tapx-panel` 和 `tapx-core`、建立系统服务并初始化面板。首次生成的管理员凭据应立即安全保存。

## 升级

升级前执行完整备份。安装器会校验发布资产结构，但不代替发布签名或 SHA-256 校验。升级后应检查：

- 面板和核心服务均处于运行状态。
- 面板、TapX 核心和内置 Xray 版本与 manifest 相符。
- 原有管理地址、默认路由和关键连接仍可用。
- 连接端诊断和代表性分流规则正常。

不要在未备份的情况下覆盖数据库、证书或现有配置。
