# 常见故障排查

## 面板无法打开

1. 检查 `tapx-panel` 服务状态和监听端口。
2. 确认面板的 HTTPS 证书和 base path 与访问地址一致。
3. 检查系统防火墙和反向代理。
4. 不要用 SSH 账号密码替代 TapX 面板管理员凭据。

## 连接端显示停止

“启用”仅表示配置允许运行，“状态”应反映实际运行时。如果显示停止，请查看该连接端的运行内核、目标地址、证书/密钥、协议参数和错误原因。

## 诊断与业务流量不一致

诊断必须经过当前连接端的真实代理协议。如果延迟、出口地址或 Speedtest 与业务流量不符，请同时检查路由选择、DNS 解析、代理进程日志和对应网卡抓包。

## 应用配置耗时过长

区分前端请求、数据库保存、运行时重载和远程节点调用的耗时。不要通过截断数据或降低刷新准确性来掩盖重复 API 请求；应先确认请求是否被重复发出，再定位后端真实阻塞点。
