# TapX v0.2.4

更新内置官方 Xray 至 v26.10.21，同步入站/出站字段，改善正常配置行为，移除不必要的组合限制。

修复面板重启时端口、路径及 HTTP/HTTPS 切换的跳转与等待问题；完善高级配置、导入、状态回读、GeoData 上传和配置应用后的恢复。

保留 TapX 自有 Raw UDP/TCP、TAP/TUN、DHCP、访问控制及策略组合能力。

提供 Linux x86-64、Linux ARM64、OpenWrt x86-64、OpenWrt ARM64 四个平台归档；两个 OpenWrt 归档均包含 APK 和 IPK。Linux 使用安装脚本，OpenWrt 按设备实际包管理器安装 APK/IPK。请核对 SHA256SUMS。

已知边界：官方内核的 OCSP/证书刷新生命周期、Realm 映射清理与端口返回、XDRIVE 缓存/后台任务、出站 socket 错误传播及 SOCKS UDP 大报文边界仍有已知限制。第三方账号实连不在本次验收范围。

本次发布依据本地与实机验收；云 CI 因 GitHub 账户计费限制未执行，不计为通过。
