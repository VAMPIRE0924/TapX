# TapX v0.2.4

## 更新内容

- 修复 NordVPN 国家列表及 NordLynx 服务器筛选请求。
- 更新内置 Xray 至 v26.10.21，同步入站与出站参数。
- 修复修改面板访问协议、端口或入口路径后，重启跳转失败的问题。
- 改进高级 JSON 配置、配置导入和运行状态显示。
- 完善 GeoData 上传及配置应用失败后的恢复。

## 下载与安装

提供 Linux x86-64、Linux ARM64、OpenWrt x86-64 和 OpenWrt ARM64 四个平台的安装包。两个 OpenWrt 归档均包含 APK 和 IPK，请按设备实际包管理器选择。

- [Linux 安装与升级](https://github.com/VAMPIRE0924/TapX/blob/main/docs/安装与升级.md)
- [OpenWrt 安装与升级](https://github.com/VAMPIRE0924/TapX/blob/main/docs/OpenWrt.md)
- [下载文件校验](https://github.com/VAMPIRE0924/TapX/blob/main/docs/发布校验.md)

升级前请保存现有配置，下载后核对同版本的 `SHA256SUMS`。

## 同版本文件更新

2026-10-24 更新了 v0.2.4 下载文件，版本号保持不变。已安装较早 v0.2.4 的用户可重新执行 Linux 安装入口，或使用 OpenWrt 包管理器的 `--force-reinstall` 重新安装对应格式的软件包。请同时重新下载当前 `SHA256SUMS`；此前保存的校验文件不适用于本次更新后的归档。
