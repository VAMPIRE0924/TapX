# v0.2.40-r5

## 更新内容

- OpenWrt 单 IP 复用客户端关闭桥接时，自动创建直接绑定 TAP 的逻辑接口，并同步地址与运行状态。可在 LuCI 中启停接口、关联防火墙区域和配置端口映射，无需额外网桥。
- 修复客户端持有与远端服务器相同公网 IP 后，新连接被本机路由截留的问题，恢复隧道重连及 DHCP 续租。
- 修复多个单 IP 客户端恢复时被管理路径检查误拦截的问题。
- 修复启用桥接但不指定外部网卡时的防火墙应用失败。

## 使用说明

- 地址仍由 TapX 内置 DHCP 客户端获取；不要在同一 TAP 上同时启动另一套 DHCP 客户端。
- 在 LuCI「网络 → 接口」中找到 `tapx_` 开头的接口，编辑其防火墙区域，再到「网络 → 防火墙 → 端口转发」配置所需服务。不会自动开放端口或修改现有防火墙区域。
- 首次安装此版本的 OpenWrt 协议支持时，会重启一次网络服务以加载协议，网络会短暂中断；已加载协议的后续升级无需因此重启网络。

## 下载与安装

提供 Linux x86-64、Linux ARM64、OpenWrt x86-64 和 OpenWrt ARM64 四个平台的安装包。
两个 OpenWrt 归档均包含 APK 和 IPK，请按设备实际包管理器选择；APK 文件名为 `tapx-0.2.40-r5.apk`。

升级前备份配置，下载后核对同一版本的 `SHA256SUMS`。
