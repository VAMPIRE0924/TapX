# 面板与对象关系

## 基础对象

- **网卡与设备**：管理系统网卡、TUN/TAP 及相关网络参数。
- **监听端**：接收来自终端或远端 TapX 的连接。
- **连接端**：定义代理出站或隧道的协议、运行内核和目标。
- **用户与 vKey**：定义身份、准入、限速和可选绑定。
- **路由**：将匹配条件与直连、阻断或指定连接端组合。

## 分流

- **接入分流**：处理通过 TapX 监听端或隧道进入的流量。
- **终端分流**：根据终端 IP、MAC 及规则选择出口。
- **DNS 分流**：为不同域名、终端或规则集选择 DNS 上游与出口。
- **GeoData**：为域名和 IP 规则提供可更新的分类数据。

## 保存与应用

新增、编辑和删除对象的对话框会直接保存该对象。只有存在组合草稿和统一应用语义的配置页，才使用页面级的“应用配置”。“重载配置”用于让运行时重新读取已保存配置，不代替保存。

## 高级配置

对外开放的低层参数会在高级配置中以完整 JSON 呈现。高级编辑器是表单能力的补充，不是无效占位；保存时会执行结构与组合校验。
