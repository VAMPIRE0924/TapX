# 面板使用说明

## 基础对象

- **网卡**：查看系统接口，并配置 TapX 可使用的物理或虚拟网卡。
- **监听端**：定义入站协议、地址、端口、运行内核、安全与传输参数。
- **用户**：配置协议凭据、速率、流量额度、有效期和可选绑定。
- **连接端**：定义代理出站或隧道目标、协议、运行内核、设备、安全和传输参数。
- **通道策略**：组合监听端、连接端、用户、设备、路由、vKey 和地址限制。
- **内核设置**：管理 TapX、内置 Xray 与外置 Xray 的运行参数和组件状态。

低层参数不会被收缩成少量预设。高级配置以完整 JSON 编辑器补充表单能力，保存时仍执行字段和组合校验。

## 分流与路由

- **接入分流**：处理通过监听端或隧道进入的流量。
- **终端分流**：按终端 IP、MAC、目标、域名和规则集选择出口。
- **DNS 分流**：按域名、终端、规则集和出口选择 DNS 上游。
- **GeoData**：管理 `geoip`、`geosite` 数据、更新状态和规则引用。
- **路由组与负载均衡**：组合多个连接端，配置优先级、探测和选择策略。
- **链路查询**：从用户、终端、监听端、连接端或规则反查实际关系。

## 保存、应用与重载

网卡、监听端、用户、连接端和其他单对象页面在新增、编辑、删除对话框内直接完成保存，不需要额外的页面级草稿按钮。

只有需要编辑一组有顺序或统一生效语义的配置页才显示“应用配置”，例如接入分流、终端分流和 DNS。应用成功后应回读最新配置与运行状态；失败时显示真实错误并保持上一份可用配置。

“重载配置”让运行时重新读取已经保存的配置，不保存草稿，也不代替新增或编辑对话框中的保存动作。

## 连接端状态与诊断

“启用”表示配置允许运行，“状态”表示真实运行结果。流量、速度和延迟来自运行时统计，停止状态不能伪装成运行中。

代理出站诊断与所选运行内核保持一致，通常包括：

- TCP/HTTP 连接检测；
- 协议真实支持 UDP 时的 UDP 请求延迟；
- 出口地址、地区和运营商信息；
- 经过该代理连接端的 Speedtest。

TapX 代理出站、内置 Xray 与外置 Xray 应使用一致的代理诊断结构，不在代理出站模式中混入无关的 TUN/TAP、通道状态或 Path MTU 项目。

## 多节点管理

页面顶部的管理范围决定当前操作对象。切换节点前确认节点名称；保存和应用会发送到当前节点，节点状态过期时应执行真实探测并更新，而不是长期展示旧状态。
